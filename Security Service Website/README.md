# Fortress Security Service

Готовый статический сайт для сервиса безопасности: лендинг, калькулятор, формы заявок, модальные окна, фильтры кейсов, FAQ, чат-помощник, PWA manifest и service worker.

## Запуск

Откройте `index.html` напрямую в браузере или запустите любой статический сервер из папки проекта.

```powershell
python -m http.server 8080
```

## Функции

- адаптивная навигация и светлая/темная тема;
- онлайн-калькулятор стоимости с сохранением результата в `localStorage`;
- заявки из форм и модальных окон сохраняются в `localStorage`;
- фильтрация кейсов, FAQ-аккордеон, чат с готовыми ответами;
- PWA-файлы для установки и офлайн-кэша.
